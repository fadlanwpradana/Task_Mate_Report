# Task Mate

Task Mate is a student productivity and community app built with Flutter:
tasks with priority scoring and reminders, a community feed, profiles, and
one-on-one and group chat.

## Running the app

The app signs in with Firebase (project `taskmatev4`) and stores tasks, the
community, and chat in Cloud Firestore. Profile settings (appearance, language,
notification switches) stay on the device.

```sh
flutter run
flutter build apk --debug   # build/app/outputs/flutter-apk/app-debug.apk
```

### Offline demo mode

To run without Firebase (fake sign-in, sample data on the device, simulated
chat replies):

```sh
flutter run --dart-define=TASK_MATE_OFFLINE=true
```

## Chat and privacy

There is no list of users. A chat starts from someone's **exact email
address** plus a first message; group members are added by email too.

Firestore layout (enforced by `firestore.rules`):

- `users/{uid}/tasks/{id}`, `users/{uid}/bookmarks/{postId}`,
  `users/{uid}/joined/{communityId}`: private to that user.
- `communities/{id}` (+ `members/{uid}`): readable by everyone signed in;
  member and post counts can only move by one, with a matching membership.
- `posts/{id}` (+ `comments/{id}`): public posts readable by everyone signed
  in; posts in private communities only by members. Likes are an own-uid
  toggle; only authors can delete.
- `users/{uid}`: display name only. Readable one at a time, never listable.
- `emailIndex/{email}`: exact email → user. Readable only by document id.
- `conversations/{id}`: members, names, last message, unread / read / typing
  state. Only members can read or update; membership can't be changed.
- `conversations/{id}/messages/{id}`: only members can read; messages can't be
  edited, deleted, or sent as someone else.

## Firebase configuration

`lib/firebase_options.dart`, `android/app/google-services.json`, and
`firebase.json` were generated by `flutterfire configure` for `taskmatev4`.

Sign-in methods: Email/Password and Google. Google sign-in on Android only
works for builds signed with a key whose SHA-1/SHA-256 is registered on the
Firebase Android app. The debug key of the development machine is registered;
add the release key before publishing:

```sh
firebase apps:android:sha:create 1:100395782426:android:b556e54716f453bd9f1ca3 <SHA> --project taskmatev4
flutterfire configure --project=taskmatev4 --platforms=android
```

After changing security rules or indexes, deploy them:

```sh
firebase deploy --only firestore
```
